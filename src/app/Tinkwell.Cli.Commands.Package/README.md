# Tinkwell.Cli.Commands.Package

CLI extension for the `tw` tool: **`tw package`** for **Tinkwell package management** — pack, unpack, verify, and resign packages from the command line.

Implements `ICliCommandProvider` (from `Tinkwell.Cli.Sdk`) and is loaded with other command assemblies via the CLI plugin model.

- [CLI user guide](../../docs/user-guide/cli.md) — command usage and global `tw` options
- [Packages reference](../../docs/reference/packages.md) — format, signing, and workflow
