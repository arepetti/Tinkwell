# Tinkwell.Cli.Commands.Lwm2m

CLI extension for the `tw` tool: **`tw lwm2m`** for **LwM2M** workflows — registration against a server and read/write of LwM2M resources for testing and operations.

Implements `ICliCommandProvider` (from `Tinkwell.Cli.Sdk`) and is loaded with other command assemblies via the CLI plugin model.

For full command syntax and examples, see the [CLI user guide](../../docs/user-guide/cli.md).
