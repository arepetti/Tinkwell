# Tinkwell.Actions

Implements **action handlers** (CoAP, MQTT, measure, and state operations) against the shared contracts in `Tinkwell.Actions.Abstractions`.
This assembly wires protocol and runtime concerns to the abstractions so runlets and integrations can dispatch actions consistently.

For handler contracts, configuration, and how actions fit into the system, see the [actions reference](../../docs/reference/actions.md).
