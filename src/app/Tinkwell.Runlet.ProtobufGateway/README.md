# Tinkwell.Runlet.ProtobufGateway

Headless runlet that **bridges gRPC services to CoAP** (and related protocol translation) through a middleware pipeline, with **service allowlisting** so only approved surfaces are exposed.

The pipeline and extension points are shared with `Tinkwell.Runlet.ProtobufGateway.Abstractions`.
For configuration, allowlisting, and behavior details, see the [protobuf gateway reference](../../docs/reference/protobuf-gateway.md).
