# Tinkwell.Cli.Commands.Plugins

CLI extension for the `tw` tool: **`tw plugins`** — **plugin lifecycle** from the command line: list, search, install, update, and uninstall CLI and runtime plugins.

Implements `ICliCommandProvider` (from `Tinkwell.Cli.Sdk`) and is loaded with other command assemblies via the CLI plugin model.

- [CLI user guide](../../docs/user-guide/cli.md) — command usage and global `tw` options
- [Plugins reference](../../docs/reference/plugins.md) — plugin model, packaging, and behavior
