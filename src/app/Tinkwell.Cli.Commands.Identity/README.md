# Tinkwell.Cli.Commands.Identity

CLI extension for the `tw` tool: **`tw identity`** commands for **account lifecycle** — signup, key management, and account deletion, against the identity backend used by the stack.

Implements `ICliCommandProvider` (from `Tinkwell.Cli.Sdk`) and is loaded with other command assemblies via the CLI plugin model.

For full command syntax and options, see the [CLI user guide](../../docs/user-guide/cli.md).
